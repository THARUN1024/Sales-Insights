## Overview

This project provides a detailed analysis of sales performance across different markets, products, and customer segments using Tableau. The visualizations help in understanding revenue trends, profit margins, and key performance indicators, enabling data-driven decision-making.

## Skills Used

- **Data Analysis**: Analyzed sales data to uncover revenue trends, profit margins, and key performance metrics.
- **Tableau**: Created dashboards and visualizations to represent revenue trends, market performance, and sales quantity.
- **Market Segmentation**: Explored sales performance across different customer segments and markets to identify top performers.

## Key Insights

1. **Revenue vs Profit Analysis**:  
   - Highest revenue observed in **Q3 2019**.  
   - Fluctuating profit margins observed across different quarters from **2017 to 2020**.

2. **Revenue by Market**:  
   - **Total revenue**: **$984.87M**.  
   - **Top markets**:  
     - **Delhi NCR**: **$519.57M**.  
     - **Mumbai**: **$150.08M**.  
     - **Ahmedabad**: **$132.31M**.

3. **Sales Quantity by Market**:  
   - **Total sales quantity**: **0.85M**.  
   - **Top markets by sales quantity**:  
     - **Delhi NCR**: **988.29K**.  
     - **Mumbai**: **383.64K**.  
     - **Nagpur**: **262.09K**.
